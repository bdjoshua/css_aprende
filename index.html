01 / CONCEPTO

¿Qué es CSS?

CSS significa Cascading Style Sheets (hojas de estilo en cascada). Es el lenguaje que describe la presentación de un documento HTML.

Contenido

HTML: títulos, párrafos, imágenes y botones.

Presentación

CSS: colores, tamaños, espacios y distribución.

Cascada

Cuando varias reglas compiten, el navegador decide cuál aplicar según importancia, especificidad y orden.

05 / CONSTRUYE UNA REGLA
¿Cuáles son la sintaxis y las reglas de CSS?
Una regla tiene un selector y un bloque entre llaves. Dentro escribimos declaraciones: propiedad: valor;
Selector: a quién. Propiedad: qué cambia. Valor: cómo cambia.
Un título para experimentar
Este párrafo también puede cambiar.
Reglas básicas: usa llaves { }, dos puntos : y separa declaraciones con ;. Los valores dependen de la propiedad: por ejemplo, 32px es un tamaño y #2563eb es un color.

07 / CLASES
¿Qué es una clase y cómo se define?
Una clase agrupa elementos que comparten un estilo. En HTML se escribe class="destacado"; en CSS se selecciona con un punto: .destacado.
.destacado { background-color: #d9fff1; color: #075c48; }
Pulsa cada tarjeta para añadir o quitar la misma clase. Una clase puede repetirse.


08 / IDENTIFICADORES
¿Qué es un identificador CSS?
El atributo id identifica un elemento único en el documento. CSS lo selecciona con #. Cada id debe aparecer una sola vez.
Título único
Un aviso importante.
Clase = un grupo reutilizable. Identificador = un elemento único. Los ejemplos usan nombres diferentes para evitar repetir ids.


09 / CONECTA LOS ARCHIVOS
¿Cómo se incorpora CSS en un documento HTML?
Resumen: style en el elemento, <style> dentro de <head>, o un enlace a un archivo externo. Para varias páginas, el archivo externo facilita mantener el diseño.

10 / UNA WEB, VARIAS PANTALLAS
¿Qué son el diseño responsivo y las media queries?
Diseño responsivo: adapta el contenido al espacio disponible. Media queries: aplican reglas cuando se cumple una condición, como un ancho de pantalla.
/* Base: tres columnas */
.rejilla { display: grid; grid-template-columns: repeat(3, 1fr); }
@media (max-width: 800px) { .rejilla { grid-template-columns: repeat(2, 1fr); } }
@media (max-width: 500px) { .rejilla { grid-template-columns: 1fr; } }
Compara: desactiva las media queries y elige móvil. Las tres columnas se mantienen. Actívalas y el contenido se reorganiza. El ancho efectivo puede limitarse al espacio de tu pantalla.
